## 二、产品定义说明

### 1. 产品定义

句子AI情报局是一款面向「句子互动」内部使用的AI 信息监控与自动提醒工具，用于定时追踪全网与句子互动及旗下产品相关的新闻、报道与舆情信息，并在出现有效信息时进行自动推送。
产品的1.0阶段，关注的是句子互动旗下的AI社工、AI普法调解员两款AI员工的全网报道。

### 2. 目标用户

公司内部的管理层、品牌/市场/公关相关人员以及需要关注外部信息变化的业务负责人

### 3. 核心使用场景

*   定期了解全网是否出现与企业相关的新报道
*   第一时间获知与公司、产品、项目相关的报道信息
*   替代人工反复搜索、刷新闻、盯关键词的低效行为

## 三、产品计划

句子情报局的迭代规划遵循MVP → 稳定化→ 易用化→ 批量化复制的产品路径，逐步演进。

### ✅ 第一阶段

该阶段阶段为MVP 验证阶段，主要的目标是验证“定向信息监控+自动提醒”是否真正有用。
**阶段重点:**
*   跑通从数据获取→ 信息处理 → 自动推送的完整链路
*   验证关键词筛选逻辑是否有效
*   验证推送频率是否对用户造成干扰

### 第二阶段

该阶段为稳定性与可维护性提升阶段，其目标为让产品可以长期运行，而不是“一次性 Demo”。
可能的优化方向包括:
*   数据抓取与写入的稳定性提升
*   嵌入微信公众号生态 -- 抓公众号的文章
*   关键词与规则的可调整性

### 第三阶段：方案模板化与场景扩展

该阶段目标为沉淀通用监控方案，并推广到不同情报场景。
在产品稳定可用后，逐步将当前有效的监控逻辑沉淀为普适方案与模板，支持快速配置不同监控对象。
优先从政务与政策情报场景开始验证，再逐步扩展到句子互动内部不同部门的项目追踪需求，包括 HR 关注的项目、组织与行业相关信息。
通过多场景实践，形成可复用的情报监控能力框架。

## 五、当前卡点

### 1. 线上部署方案

**方案一：云函数定时触发**
通过阿里云或腾讯云云函数部署脚本，使用定时触发器执行抓取，并写入飞书表格。
**优点：** 架构最轻量、改动最小、成本可控，与现有 MVP 技术路线一致。
**缺点：** 需补齐云部署与日志监控能力，需要钱。

**方案二：n8n 自动化工作流**
将爬取模块 + 大模型处理 + 飞书写入统一编排进 n8n，通过定时器自动执行。
**优点：** 稳定、可视化、易维护。
**缺点：** 初期配置复杂，偏重型，不适合当前 MVP 阶段。
参考：“[N8N刚学就要过时了？”别慌，过时的只是“体力活”，而不是工具！（附保姆级部署指南）](https://new.qq.com/rain/a/20231123A03J1Z00)

**方案三：扣子（Coze）自动化流程**
用扣子重构全链路流程，并结合其 AI 能力做内容处理。
**优点：** 对非技术同学友好，利于模板化复制。
**缺点：** 需大规模重构，时间成本高，不适合当前阶段。

### 2. 微信生态内容无法直接搜索

*   **问题说明:**
    当前句子 AI 情报局在“全网监控”中存在结构性盲区，主要体现在微信公众号内容无法被常规搜索API 覆盖，直接影响政务、行业机构及企业官方信息的监控完整性。

*   **已验证可行路径:**
    已探索出通过 WEWERSS 抓取微信生态内容，并接入飞书 API 的方案，可将公众号数据纳入现有“抓取→ 写入飞书多维表格 → 自动推送”链路。本地环境已验证可行，但线上稳定部署方式尚未最终确定
    > 参考: [用飞书多维表格搞定了公众号自动推送，我才明白什么是高效阅读](https://sspai.com/post/74026)

## 六、产品实现路径

### 3. 第一阶段

*(流程图展示：谷歌搜索API -> python爬虫数据 -> Trae辅助编程 -> 有新增消息 -> 录入 -> 飞书多维表格 -> 机器人通知；以及 无新增消息 -> 录入“无更新” -> 飞书多维表格 -> 机器人通知)*

#### 3.1 学会使用API获取数据

用AI辅助编写爬虫程序，通过谷歌 API自动抓取新闻内容。你只要告诉它目标（比如抓取包含"海淀区、东升镇、AI社工、句子互动"的新闻），AI就能自动生成对应的调用代码。

通过API直接写入飞书多维表格，用飞书多维表格的字段捷径功能，当你抓取到新闻后，自动进行分类总结、情绪判断、关键词提取等处理。

#### 3.3 自动化推送

**具体实施步骤**

**3.3.1 先创建飞书群机器人**
你需要在飞群里添加一个自定义机器人。在飞书群设置里找到"机器人"选项，点击"添加机器人"，选择"自定义机器人"。设置好机器人头像和名称后，会给你一个webhook地址，这个很重要，要保存好。

**3.3.2 配置飞书多维表格自动化**
在你的多维表格里，可以这样设置自动化规则:
*   **触发条件:** 新增记录时
*   **筛选条件:** 当你通过API抓取到新闻并写入表格后，检查关键词字段是否包含"海淀区、东升镇、AI社工、句子互动"
*   **执行动作:** 发送webhook请求到你保存的机器人地址

**3.3.3 消息格式化**
在自动化配置中，你可以设计推送消息的格式

```
代码块
1 【句子互动舆情监控】
2 📋 标题:
3 🕒 时间:
4 🔗 链接:
5 📰 来源:
6 📝 摘要:
```
